# หอพุทธศิลป์ · ทัวร์เสมือนจริง 360°

เว็บไซต์เยี่ยมชมหอพุทธศิลป์ด้วยภาพ 360° ที่ผูกต่อกันแบบ **Street View**
คลิกลูกศรบนพื้นเพื่อเดินไปห้องถัดไป แล้วระบบจะหันหน้าไปทิศเดียวกับที่เดินมาให้เอง

## ความสามารถ

- ลูกศรบนพื้นแบบ Street View ที่ระบบ**คำนวณทิศให้อัตโนมัติ**จากตำแหน่งบนแผนผัง
- เดินแล้วหันหน้าต่อเนื่อง (ทิศที่เดินเข้า = ทิศที่มองในจุดถัดไป)
- ลิงก์สองทางอัตโนมัติ (ผูก A → B แล้ว B มีลูกศรกลับ A)
- แผนผังขนาดเล็ก (mini-map) พร้อมกรวยบอกทิศที่กำลังมอง คลิกจุดบนแผนผังเพื่อวาร์ปได้
- ปุ่ม/คีย์ **W** “เดินหน้า” ไปยังจุดที่อยู่ในทิศที่กำลังมอง
- ข้อมูลงานศิลปะ 70 ชิ้นจากป้ายข้อมูล — คลิก ⓘ ที่วัตถุในภาพ 360° หรือค้นหาจากรายการ ❖
- แผนผังห้องแบบกล่อง คำนวณจากการเปรียบเทียบภาพทุกคู่ และลูกศรเดินได้หลายทิศจากทุกจุด
- ลิงก์ตรงไปยังแต่ละจุด เช่น `index.html#p130`, หมุนอัตโนมัติ, เต็มจอ, รองรับมือถือ
- ไม่ต้องใช้ CDN — ไลบรารี [Pannellum](https://pannellum.org/) อยู่ใน `vendor/` แล้ว

## เริ่มใช้งาน

ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (เปิดไฟล์ตรง ๆ แบบ `file://` เบราว์เซอร์จะไม่ยอมโหลดภาพเข้า WebGL)

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

ขึ้นเซิร์ฟเวอร์จริง (cPanel / Nginx / Docker / GitHub Pages) ดูขั้นตอนใน [`deploy/README.md`](deploy/README.md)
— `bash deploy/build.sh` จะรวมเฉพาะไฟล์ที่เว็บใช้ (~37 MB ไม่รวม `Asset/`) ไว้ใน `deploy/dist/`

## ภาพ 360° ที่ใช้

ใช้ภาพ `Asset/20210903_044411_*.jpg` (6080×3040) จำนวน 53 จุด เรียงตามลำดับการถ่าย
(ตัด `_224` ออกเพราะถ่ายซ้ำตำแหน่งเดียวกับ `_215`) แล้วย่อเหลือ 4096×2048 ไว้ใน `images/panoramas/`
เพื่อให้เปิดบนมือถือได้ เส้นทางเริ่มจากหน้าทางเข้า (`_220`) → ระเบียง → ประตู → ห้องจัดแสดงทุกโซน

### ผูกภาพเป็น Street View อัตโนมัติ

```bash
pip install numpy scipy opencv-python-headless
python3 tools/pairs.py window 5   # เปรียบเทียบภาพทีละคู่ (ผลเก็บใน tools/links-cache.json)
python3 tools/build_tour.py       # คำนวณแผนผัง + ลูกศร + จุดข้อมูล แล้วเขียน data/tour.js
```

1. **เปรียบเทียบภาพทีละคู่** (`tools/pairs.py`, `tools/estimate_links.py`) — จับคู่จุดเด่น (SIFT)
   แล้วหา Essential matrix บนทรงกลม ได้ทิศที่ภาพอีกภาพถูกถ่าย และมุมที่กล้องหมุนต่างกัน
   ทำกับทุกคู่ที่อยู่ใกล้กัน (ไม่ใช่แค่คู่ติดกันตามลำดับถ่าย) รวม 276 คู่
2. **คำนวณแผนผังทั้งหมดพร้อมกัน** (`tools/solve_map.py`) — ใช้ทุกคู่ที่เชื่อถือได้ (141 คู่)
   หามุมหันและตำแหน่งของทุกจุด ตัดคู่ที่ขัดแย้งกับคู่อื่นออกอัตโนมัติ
   แล้วหมุนแผนผังให้ผนังขนานแกน เพราะห้องเป็นกล่องสี่เหลี่ยม
3. **ลูกศรหลายทิศ** — แต่ละจุดมีลูกศรไปยังจุดข้างเคียง 2–6 ทิศ (เลือกจุดใกล้ก่อน และไม่ให้ลูกศร
   สองอันชี้ใกล้กันเกิน 35°) เดินได้ทั่วห้องโดยไม่ต้องย้อนตามลำดับการถ่าย

ภาพคู่ที่ต่างกันมากจนจับจุดไม่ได้ (หลังองค์พระประธาน `_181`, ประตูออกระเบียง `_195`→`_197`/`_199`)
กำหนดทิศด้วยมือใน `MANUAL` ชื่อโซน/คำบรรยายแก้ใน `ZONES` แล้วรันสคริปต์ใหม่
(ถ้ารันสคริปต์ใหม่ `data/tour.js` จะถูกเขียนทับ)

### ข้อมูลงานศิลปะ

ป้ายข้อมูล `Asset/bda-mcupr-1..70.png` แปลงเป็น `images/artworks/aNN.jpg` และแสดงเต็มใบเมื่อคลิก ⓘ
หรือเลือกจากรายการงานศิลปะ (ปุ่ม ❖ มีช่องค้นหา) ตำแหน่งในภาพ 360° อยู่ใน `tools/artworks.json`

- **หาอัตโนมัติ** (`tools/locate_artworks.py`) — ตัดภาพ 360° เป็นมุมมองย่อยความละเอียดเต็ม
  แล้วจับคู่กับภาพถ่ายในป้าย ผลดิบอยู่ใน `tools/artwork-matches.json` (ตรวจด้วยตาก่อนใช้ทุกชิ้น)
- **กำหนดด้วยมือ** — ชิ้นที่หาอัตโนมัติไม่ได้ ใส่ใน `placements` ของชิ้นนั้น:
  `{ "pano": "122", "yaw": -40, "pitch": -15, "source": "manual" }`
  หาค่า yaw/pitch ได้จาก `?edit=1#p122` แล้วคลิกที่วัตถุ
- ชิ้นที่ยังไม่มีตำแหน่งยังอยู่ในรายการงานศิลปะ (เลขขอบประ) คลิกแล้วเปิดป้ายข้อมูลได้

### รูปแบบข้อมูลใน `data/tour.js`

```js
{
  id: "p130",
  title: "โซนพระพุทธรูป (1)",
  image: "images/panoramas/p130.jpg",
  map: { x: 50, y: 66 },        // ตำแหน่งบนแผนผัง
  northOffset: 12.3,            // yaw ในภาพที่หันไป "ด้านบนแผนผัง"
  links: [{ to: "p136" }],      // ลูกศรคำนวณจาก map + northOffset (ลิงก์กลับสร้างให้อัตโนมัติ)
  infos: [{ yaw: -150, pitch: 0, title: "...", text: "..." }]   // จุดข้อมูล ⓘ (ไม่บังคับ)
}
```

- กำหนดลูกศรเองได้: `{ to: "p105", yaw: -3.2, pitch: -20 }`, `oneWay: true`, `targetYaw`
- เพิ่มจุดข้อมูล ⓘ ให้วัตถุจัดแสดง: เปิด `?edit=1#p130` คลิกที่วัตถุ แล้วคัดลอก `{ yaw, pitch }` ที่แสดงไปใส่ `infos`
- ใส่รูปแผนผังอาคารจริงได้ที่ `floorPlan.image` (ถ้าไม่ใส่ แผนผังจะวาดจากเส้นทางเดินอัตโนมัติ)

## โครงสร้างไฟล์

```
index.html                 หน้าเว็บ
css/style.css              หน้าตา
js/app.js                  ตัวผูกภาพแบบ Street View, แผนผัง, ปุ่มต่าง ๆ
data/tour.js               ข้อมูลจุดชม ← แก้ไฟล์นี้เป็นหลัก
images/panoramas/          ภาพ 360°
vendor/pannellum/          ไลบรารีแสดงภาพ 360° (MIT)
Asset/                     ภาพต้นฉบับ
tools/build_tour.py        สร้างทัวร์จากภาพใน Asset/
tools/pairs.py             เปรียบเทียบภาพ 360° ทีละคู่ (ขนานกัน 4 process)
tools/solve_map.py         คำนวณแผนผังทั้งหมดจากผลเปรียบเทียบ
tools/locate_artworks.py   หาตำแหน่งงานศิลปะจากภาพในป้ายข้อมูล
tools/artworks.json        ชื่อ + ตำแหน่งงานศิลปะ 70 ชิ้น (แก้ไฟล์นี้เพื่อเพิ่ม/ย้ายจุด ⓘ)
images/artworks/           ภาพป้ายข้อมูลงานศิลปะ
images/logo/               ตราสัญลักษณ์ มจร (หัวเว็บ, favicon, หน้าโหลด) จาก Asset/cropped-*mcu-logo*
tools/estimate_links.py    คำนวณทิศเดิน/มุมหมุนระหว่างภาพ 360° สองภาพ
tools/links-cache.json     ผลคำนวณที่เก็บไว้
```
