# หอพุทธศิลป์ · ทัวร์เสมือนจริง 360°

เว็บไซต์เยี่ยมชมหอพุทธศิลป์ด้วยภาพ 360° ที่ผูกต่อกันแบบ **Street View**
คลิกลูกศรบนพื้นเพื่อเดินไปห้องถัดไป แล้วระบบจะหันหน้าไปทิศเดียวกับที่เดินมาให้เอง

## ความสามารถ

- ลูกศรบนพื้นแบบ Street View ที่ระบบ**คำนวณทิศให้อัตโนมัติ**จากตำแหน่งบนแผนผัง
- เดินแล้วหันหน้าต่อเนื่อง (ทิศที่เดินเข้า = ทิศที่มองในจุดถัดไป)
- ลิงก์สองทางอัตโนมัติ (ผูก A → B แล้ว B มีลูกศรกลับ A)
- แผนผังขนาดเล็ก (mini-map) พร้อมกรวยบอกทิศที่กำลังมอง คลิกจุดบนแผนผังเพื่อวาร์ปได้
- ปุ่ม/คีย์ **W** “เดินหน้า” ไปยังจุดที่อยู่ในทิศที่กำลังมอง
- จุดข้อมูล ⓘ สำหรับอธิบายพระพุทธรูป/วัตถุจัดแสดง
- ลิงก์ตรงไปยังแต่ละจุด เช่น `index.html#main-hall`, หมุนอัตโนมัติ, เต็มจอ, รองรับมือถือ
- ไม่ต้องใช้ CDN — ไลบรารี [Pannellum](https://pannellum.org/) อยู่ใน `vendor/` แล้ว

## เริ่มใช้งาน

ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (เปิดไฟล์ตรง ๆ แบบ `file://` เบราว์เซอร์จะไม่ยอมโหลดภาพเข้า WebGL)

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

หรืออัปโหลดทั้งโฟลเดอร์ขึ้น GitHub Pages / โฮสติ้งใดก็ได้ (เป็นเว็บ static ล้วน)

## ใส่ภาพ 360° จริง

1. ถ่ายภาพ 360° (เช่น Insta360 / Ricoh Theta / GoPro Max) แล้ว export เป็น **equirectangular JPG อัตราส่วน 2:1**
   แนะนำกว้าง 6000–8000 px (มือถือบางรุ่นรองรับสูงสุด 4096 px — ถ้าต้องการรองรับทุกเครื่องให้ย่อเหลือ 4096×2048)
2. วางไฟล์ใน `images/panoramas/` (ตอนนี้มีภาพตัวอย่าง placeholder อยู่ ให้เขียนทับได้เลย)
3. แก้ `data/tour.js` ให้ตรงกับจุดถ่ายจริง

### ผูกภาพเป็น Street View (`data/tour.js`)

```js
{
  id: "lobby",                              // รหัสจุด
  title: "โถงต้อนรับ",
  image: "images/panoramas/02-lobby.jpg",
  map: { x: 50, y: 66 },                    // ตำแหน่งจุดถ่ายบนแผนผัง (%)
  northOffset: 0,                           // yaw ในภาพที่หันไป "ด้านบนแผนผัง"
  links: [{ to: "main-hall" }, { to: "murals" }],   // เดินไปจุดไหนได้บ้าง
  infos: [{ yaw: -150, pitch: 0, title: "...", text: "..." }]
}
```

**ขั้นตอนผูกภาพ**

1. วางตำแหน่ง `map` ของทุกจุดตามตำแหน่งที่ตั้งขาตั้งกล้องจริง (มองแผนผังจากด้านบน, x ซ้าย→ขวา, y บน→ล่าง)
2. เปิด `http://localhost:8000/?edit=1#<id>` แล้ว**หมุนภาพให้เครื่องหมาย + กลางจอหันไปทางด้านบนของแผนผัง**
   อ่านค่า `yaw` บนจอ แล้วใส่เป็น `northOffset` ของจุดนั้น — ทำทุกจุด
3. ใส่ `links` ระหว่างจุดที่เดินถึงกันได้ ลูกศรจะไปอยู่ตรงทิศที่ถูกต้องเอง
4. ถ้าลูกศรยังไม่ตรงประตูพอดี (เช่น ทางเดินอ้อม) กำหนดเองได้: `{ to: "murals", yaw: -75, pitch: -20 }`
5. จุดข้อมูล ⓘ: ในโหมด `?edit=1` คลิกที่วัตถุ แล้วคัดลอกค่า `{ yaw, pitch }` ที่แสดงไปใส่ใน `infos`

ตัวเลือกอื่นของลิงก์: `oneWay: true` (ไม่สร้างลูกศรกลับ), `targetYaw` (กำหนดทิศที่มองเมื่อไปถึง)
ตัวเลือกอื่นของจุด: `yaw` / `pitch` (มุมมองเริ่มต้นเมื่อเปิดจุดนั้นตรง ๆ)

### แผนผังอาคาร

ใน `floorPlan` ใส่รูปแผนผังจริงได้ที่ `image: "images/floorplan.png"` (ควรเป็นรูปสี่เหลี่ยมจัตุรัส)
หรือใช้ `rooms` วาดกรอบห้องอย่างง่ายแบบที่มีอยู่ตอนนี้

## โครงสร้างไฟล์

```
index.html                 หน้าเว็บ
css/style.css              หน้าตา
js/app.js                  ตัวผูกภาพแบบ Street View, แผนผัง, ปุ่มต่าง ๆ
data/tour.js               ข้อมูลจุดชม ← แก้ไฟล์นี้เป็นหลัก
images/panoramas/          ภาพ 360°
vendor/pannellum/          ไลบรารีแสดงภาพ 360° (MIT)
tools/make_placeholders.py สร้างภาพตัวอย่างจาก data/tour.js (pip install pillow)
```
